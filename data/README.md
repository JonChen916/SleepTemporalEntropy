# Data access

No participant-level data are distributed with this repository.

The Sleep Heart Health Study (SHHS) data used in the associated study are
hosted by the National Sleep Research Resource (NSRR):
<https://sleepdata.org/datasets/shhs>. Access is controlled by NSRR and requires
an approved data request and acceptance of the applicable Data Access and Use
Agreement. Users must obtain the data directly from NSRR and comply with its
security, citation, acknowledgement, and reuse conditions.

Do not commit EDF files, NSRR participant XML annotations, derived
participant-level tables, identifiers, or credentials. The repository's
`examples/synthetic_sleep_stages.xml` file is artificially constructed and is
not derived from any participant.
