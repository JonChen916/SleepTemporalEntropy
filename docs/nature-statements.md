# Manuscript availability statements

## Data availability

The Sleep Heart Health Study data analysed in this study are available through
the National Sleep Research Resource
(https://sleepdata.org/datasets/shhs). Access requires submission and approval
of a data-access request and acceptance of the applicable Data Access and Use
Agreement. Owing to these third-party access conditions, participant-level data
cannot be redistributed by the authors. Synthetic data sufficient to verify
the software interface and metric calculations are included in the archived
code repository.

## Code availability

The reference source code used to calculate Sleep Temporal Entropy is available
at GitHub (https://github.com/JonChen916/SleepTemporalEntropy) and archived on
Zenodo at https://doi.org/10.5281/zenodo.21926192. The version corresponding to
this article is version 1.0.0 and is released under the MIT License.

## Software reference
